# harmony-schools-assets

Shared design CSS and JS for the three Harmony Schools sites built on Tilda (Start, STEAM, Global), served by jsDelivr.

**Temporary.** This repo exists only while the design is still changing. Tilda truncates large project HEAD code, so each Tilda project carries a tiny HEAD loader (under 1 KB) that points at these files instead of pasting 230 KB of CSS into every page. At handover the final CSS is baked back into Tilda and this repo is archived.

## Files

| File | What |
|---|---|
| `dist/<site>.css` | The site's design CSS: Lenis, the site layer (homepage-only rules are gated by `html[data-hs-home]`), the shared system, the site polish, footer, contact, news and header layers. Minified. |
| `dist/<site>.js` | Head script, loaded synchronously: marks homepages, sets the site/language attributes (hs-init), injects the site's logo symbol, runs the typograph (typeset.js) and, on STEAM and Global, the news state script. |

`<site>` is `start`, `steam` or `global`.

## URLs

The Tilda HEAD loaders point at the moving branch `live`, so a release needs no Tilda edit:

```
https://cdn.jsdelivr.net/gh/theakhmetzhan/harmony-schools-assets@live/dist/steam.css
https://cdn.jsdelivr.net/gh/theakhmetzhan/harmony-schools-assets@live/dist/steam.js
```

## Rules

- Do not edit `dist/` by hand. The files are generated by `assemble.py --cdn live` in the Harmony build workspace and copied here.
- Every release is a tag (`v1`, `v2`, ...) on `main`; `live` is fast-forwarded to it (`git push origin vN:live`, no force). Never move or delete a tag.
- After moving `live`, purge each file at `https://purge.jsdelivr.net/gh/theakhmetzhan/harmony-schools-assets@live/dist/<file>` and check that the CDN serves the new bytes.
- Rollback rolls forward: `git checkout <older tag> -- dist`, commit, tag (for example `v3.1`), push it to `main` and `live`, then purge.
